# 维修台视觉精修

[打开三组前后对照](review.html)。下载 HTML 后可以直接离线打开，选择并排查看或用键盘在同一位置切换原图与改稿。

原版的队列与编辑器各有一块重阴影，W-02 与相邻工单又采用相同的行样式。精修保留了工单顺序、墨绿色品牌、优先级与报错色。当前行增加左线和浅底，编辑器标题标出正在处理的工单；队列和编辑器的边框、阴影也作了调整。在窄屏看不到右侧编辑器时，队列内仍能辨认当前对象。

| 对照 | 观察与验证 |
| --- | --- |
| 1280 × 850 桌面、390 × 844 手机 | 同一份本机样例数据，比较 W-02 在队列与编辑器之间的对应关系。 |
| 390 × 844 保存失败 | 两版各输入同一备注，触发示例的一次性保存失败。用编辑器顶部定位截图，确认提示、草稿和重试按钮仍在。重试后刷新，核对输入框与本机存储。 |

[原始维修台](../../examples/repair-desk/index.html)与[相对原版的精修补丁](polish.patch)可用于复现。在仓库副本中运行 `git apply benchmarks/unslop-repair-desk/polish.patch`，即可打开并操作候选版。本例验证视觉修改后关键流程能否继续工作，未做真人偏好评审。
