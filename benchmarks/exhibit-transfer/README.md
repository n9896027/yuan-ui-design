# 展签编辑器迁移验证

[同一份任务](brief.md)要求保留馆藏号、旧短注、空值和切换展品前的草稿。原仓库的存储接口会替换整条记录。新题由独立实施者第一次完成，此后知道结果的修正单独保留。它属于开发回归，不计入与其他技能的匿名比较。

| 运行版本 | 浏览器结果 | 对原接口的影响 |
| --- | --- | --- |
| 原始页面 | 3/8 | 可复现无改动保存破坏记录、元数据丢失及跨展品草稿回退 |
| 独立首稿 | 8/8 | 把存储的完整替换改成了局部合并 |
| 首稿接回原存储 | 6/8 | 未改保存和隐藏字段两项失败 |
| 修正后的调用方接回原存储 | 8/8 | 保存时读取完整记录，更新短注，保留原有替换语义 |

在仓库根目录运行 `npm ci`、`npx --no-install playwright install chromium` 和 `npm run test:transfer`。脚本用四个独立离线上下文重组冻结的原稿和补丁，逐一核对失败项。这里的 8 项包括一项页面无异常检查。
