# 银幕之前：微信小程序

导入微信开发者工具时选择本目录为项目根目录。页面链为节目单首页 → 影片详情；微信导航栈负责返回并恢复首页，收藏在 `wx` 本机存储中持久化，详情页提供系统转发。收藏不承诺跨设备同步。

唯一内容源是上一级的 `../programme.json` 和其中声明的图片。首次导入或节目单更新后运行：

```bash
python3 scripts/sync_programme.py
python3 scripts/sync_programme.py --check
```

同步使用同盘硬链接以避免重复占用图片空间；无法硬链接时才复制。小程序需要独立携带资源，所以移交项目目录时应保留 `assets/`。本仓库未安装微信开发者工具：这里只验证工程 JSON、同步校验与收藏状态源码，尚未验证微信真机、分享面板和宿主返回手势。

`node scripts/test_storage.js` 在本地替身环境走通打开影片、收藏、返回、重新进入、写入失败、损坏数据保护与转发路径。工程使用游客 AppID 供导入预览。好友实际收到卡片和真机操作需要在对应微信环境验证。
