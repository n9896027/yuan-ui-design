# Agentic UI Contract

在设计或审计会调用工具、流式执行、请求授权、等待用户决定、委派子任务或修改外部状态的 AI 功能时读取本文件。AI 是完成用户任务的执行者；对话只是其中一种界面，不是默认壳层。

## 先选择任务表面

根据用户要判断或操作的对象选择表面：

- 解释、追问、开放输入：对话；
- 多对象取舍、参数配置、审批：比较表、表单或差异预览；
- 空间、时间或依赖关系：画布、时间线或计划视图；
- 高影响改动：提交前差异、范围和恢复路径，而不是一句“已处理”。

不要为了 AI 而增加聊天侧栏。任务表面必须连接同一个 source of truth，并在对话、卡片或独立页之间保留同一 action identity。

## 行动契约

为适用的 agent 动作呈现：目标、参数、影响范围、当前授权、可逆性、结果和下一步。区分下列状态，不把流程词当作结果：

| 状态 | 用户应知道什么 |
|---|---|
| Draft / proposed | 只是提议；尚未执行。 |
| Awaiting approval / input | 等待何人决定、决定什么、可否编辑。 |
| Running | 已开始的真实工作和可信进度。 |
| Partial | 已完成与未完成部分、继续或停止的选择。 |
| Succeeded / failed | 真实结果、证据与可行恢复。 |
| Cancel requested | 已请求停止，但尚未证明停止。 |
| Cancelled | 已确认停止；此前已完成的副作用仍存在。 |
| Reverted | 已确认撤销的范围与仍无法撤销的结果。 |
| Outcome unknown | 先查询 source of truth；不可盲目重试副作用。 |

按动作影响、对象、内容与现有授权判断批准边界；超出仍有效的授权时才请求必要确认。沿用用户授权、策略和上下文，不把每次 tool call 都变成无意义确认。

## 提议、执行与恢复

- 预览或计划和实际提交必须可辨。只有 source of truth 确认后，才显示“已发送”“已保存”或“已完成”。
- 流式文本、计划或组件更新不得覆盖用户正在编辑的字段。显示冲突、采用建议或保留我的修改，而不是静默替换。
- 进度要来自可观察的步骤、工具事件或状态；不能用 token 输出、思维链或虚构百分比冒充进度。可展示简短的行动摘要、当前步骤和已完成事实。
- 产品支持切走后继续时，将暂停表示为可持久化的任务状态，不只存在于聊天气泡。恢复时绑定原 run、action、approval 和版本；若身份或前提过期，重新检查授权是否仍有效。不支持恢复时明确保留边界，不暗示已有存储能力。
- 取消请求不等于已取消；撤销不等于从未发生。结果未知时优先读取真实状态，不重复发出可能有副作用的请求。
- 重试、继续和重新开始应符合实际幂等、持久化和权限契约。副作用未知时优先查询；不能安全继续且确需用户决定时再询问，不为本地草稿操作增加审批。

批量任务将用户勾选范围与生成结果分开保存；流式事件、编辑和发送反馈不能静默重选对象。审阅确认应绑定同一 run、对象、参数与内容；其中任一变化后，旧确认不可继续提交。发送中、已发送或结果未知的项目不能走普通重发路径；未知项先查询。仅禁用前端按钮不能证明服务端幂等或权限执行。

## 人机协作与可访问性

- 让用户能暂停、取消、修正参数、拒绝提议、接管下一步，并看到这些选择产生的后果。
- 多 agent 或子任务要标出谁完成了什么、哪些结果仍待确认；不要把并行活动伪装为单一原子动作。
- 用户输入、焦点与滚动位置优先于新流式内容。新卡片和更新不可抢走焦点；仅对关键状态变化做节流后的礼貌播报。
- 值保留不等于能继续编辑。优先稳定编辑控件的 DOM 身份，增量更新结果，避免每个流式事件重建正在输入的子树。若必须恢复焦点，也要保留选区、插入点和滚动，并单独检查 composition/原生 IME 边界。
- 用户可在 Reduced Motion、键盘、屏读和小屏条件下完成同一批准、修正、取消与恢复路径。

## 适用的验证

当功能包含相应状态时，验证：提议未执行、批准带编辑、拒绝、暂停后刷新或重连、取消请求与最终结果分离、部分结果、未知结果的查询、冲突时保留手改，以及高影响动作的授权边界。用 action/run ID、状态、请求或 trace 证明；不要只截取聊天画面。

流式编辑至少用逐键输入跨过后续更新，再检查文本、当前焦点与插入点；一次 `fill()` 后只比对最终值会漏掉持续输入中断。模拟键盘输入不能证明真实中文 IME 组合输入已通过。

含批量发送时，再检查：取消勾选后跨一次真实更新，审阅范围仍准确；审阅后改内容使旧确认失效；未知结果的查询不增加发送次数。含任意文本备注时，用换行、`<`、`&` 和标签边界文本确认它们仍是字面文本，不破坏相邻控件。合成 composition 事件仅能验证应用处理器，不能作为原生输入法验收。

## 协议映射（可选）

协议是实现选择，不是产品形态。AG-UI 的 interrupt/resume、状态和活动事件可承载上述生命周期；实际能力应按版本和 runtime capability 检测，不能假定每个 adapter 完整支持。相关规范：
