# Tianshu UI Adapter

仅在任务明确属于天枢时读取。它是领域适配，不是通用 UI 模板。

## 产品优先级

- 先接住人，再看系统。
- 陪伴优先，不制造依赖。
- 事实源可信；镜像、registry 或来源漂移要显性但不制造恐慌。
- 默认排除测试用户，避免虚假繁荣。
- 工具自律，不把雷达或预测做成算命机器。
- 真实运营和可维护性高于仪式感或炫酷。

## 界面含义

- 健康状态通常比增长数字更靠前，但具体排序仍服从当前运营任务。
- 用户生命体征、风险和需要处理的异常优先于总调用量。
- AI 建议展示来源、置信/不确定性、范围和用户控制。
- 真相源、镜像和 registry 关系可追溯；不要以装饰性“系统在线”掩盖漂移。
- 陪伴协议通过措辞、动作、节奏和安全边界体现，不只放在说明页。

不要把这些原则机械翻译成固定暗色驾驶舱、生命体征动画或右侧 AI 助手。先按具体角色与任务选择信息架构。
