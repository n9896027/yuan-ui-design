# Skill Evaluation

只在维护本 skill、比较版本或建立回归任务时读取。普通 UI 实施不需要运行整套评测。

## 固定任务

使用 [../evals/tasks.json](../evals/tasks.json) 的三个真实请求：内容网站方向、高密度工具局部修复、AI 工作台规格。`prompt` 是给执行者的请求，`context` 是原始产品材料，不是标准答案。

默认评测范围是设计规格和行为决策，因此证据为 `static`。要比较实际视觉、可用性或性能，必须让两个版本都实现同一任务、运行同一环境并收集相应证据；不能从规格推断这些质量已提升。涉及空间体验的规则变更时，再增加一个带真实状态后果的教学/空间任务。

修改宿主或产品 3D 路由时，使用 [平台与空间任务](../evals/platform-spatial.json)。同一组使用相同原始材料，分别交付每道题的规格；比较是否出现会改变导航、观察结果、配置提交或验收方法的具体决定。保留旧套件用于检查回归。

改动实施或验证规则时，再使用 [../evals/runtime-task.json](../evals/runtime-task.json) 的设备编辑运行任务。原始 [HTML fixture](../evals/fixtures/editor.html) 刻意保留布局与失败丢稿缺陷；复制到隔离目录后修复，不将修复写回原始 fixture。先证明缺陷存在，再按契约验证结果。普通用例无需运行这套评测；没有浏览器时标明未运行。

要评价实际页面呈现和工作流，读 [rendered-evaluation.md](rendered-evaluation.md)，使用配套的原始材料、Mock 和浏览器函数。成品样例见 [visual-case-library.md](visual-case-library.md)，不要将单轮代理偏好外推为稳定优势。

## 配对方式

真实仓库的实施验证按 [repository-integration.md](repository-integration.md) 选一个范围明确的主链。保留入口、组件/状态契约、来源 commit 与当前工作树、改动范围、运行构建和适用失败恢复；不随 skill 分发项目凭据、私人数据或完整用户仓库。已有应用与一次局部修复的前后结果是实施案例，不能称为新旧 skill 的独立 A/B。首次源码、未通过项与后续修复分开记录；修好后通过不能改写首轮结果。

1. 修改前保留技能完整副本，两个版本使用相同任务、原始材料、模型、推理设置、工具和输出预算。记录不能控制的差异；没有受控模型配置就不宣称严格因果。
2. 为每个版本建立隔离工作目录。独立执行者只收到待用技能路径、`prompt`、`context` 和输出位置，不收到本次改动、预期问题或评分项；不要读取另一个版本的输出。
3. 可以用同一执行者依次完成一个版本的三项任务，但两个版本必须采用相同分组；不要把执行者身份差异解释为技能效果。输出隐藏版本名称，交给未参与生成的评审者比较。
4. 简单冒烟可每项一次。要声称稳定优势，应增加独立重复，逐任务报告原始结果；不得靠一次总分掩盖主链缺陷。

## 评审依据

先审查是否满足原始请求，再比较：

| 维度 | 可观察的证据 |
|---|---|
| 任务适配 | 结构、密度和媒介选择能由真实任务解释；局部改动没有变成无关重设计 |
| 设计具体性 | 字体/布局/内容/素材有可实施选择，方向差异不是只换色；规格无法证明成品好看 |
| 状态与真实性 | 草稿、已提交、失败和结果未知可辨；没有虚构 API、保存、审批或持久化事实 |
| 用户控制 | 适用时可编辑、可取消、可恢复；保护手改，已有授权不重复询问 |
| 系统一致性 | 使用材料中已有组件与模式；没有设计源时不强制 Figma 或制造第二套系统 |
| 验证与成本 | 提出与任务匹配的可断言检查，未运行就标未验证；记录耗时/调用量的实际值 |

逐任务给出 `A 更好 | B 更好 | 相当 | 证据不足`，列出支持判断的具体片段与缺陷。代理评审标明是 Agent 判断，不冒充人类试用、屏读或视觉认可。若做数值量表，先定义尺度并保留逐项记录；不把主观评分写成客观性能指标。

## 验收与回归

- 检查触发边界：普通前端、AI 工具、仅视觉图、纯后端分别是否路由正确。
- 检查新增参考可被入口找到，外部能力有适用条件；删除与已有规则重复的泛化约束。
- 执行 `skill-creator/scripts/quick_validate.py`、证据校验器 `--self-test`；新增或修改脚本再运行相关行为测试。
- 保留评测任务版本、模型/环境、输出、评审和未测项；只有用户要求时才把报告写入项目。改动技能文件不等于已验证视觉质量提升。
